## Release gates and honest limits

- Real Legacy inventory/assets, client-approved pricing/cancellation/accessible-room rules, legal entity, privacy notice, retention and lease terms are not supplied.
- Actual Paynow merchant/currency/method sandbox and public HTTPS callback tests are blocked by credentials/account setup. Messaging delivery, external e-sign, ERP/SIS/PMS API and WhatsApp approvals are not verified.
- Local encrypted private storage is implemented; production KMS, encrypted disks, object-storage lifecycle, offsite backup and host monitoring/alerts require deployment design and tests.
- Privacy access/export and review/hold/decline are implemented; irreversible erasure remains held for approved retention/legal-hold policy and controlled operator execution. No erasure is falsely marked complete.
- CSV/manual connectors and read APIs work locally. Provider-specific write synchronization and outbound integration webhook delivery are not claimed implemented or live; selecting external systems/mappings is a required input.
- Browser checks cover representative flows, not complete positive/negative browser automation for every J01–J13 subscenario. Manual screen-reader review, broad independent ASVS/penetration testing, production-volume load tests and production disaster recovery remain release gates.
- CI configuration is supplied; GitHub run status is reported separately after push. Local command success is not proof of remote CI, publication, merge or production deployment.

No claim of full mandatory-scope production acceptance is made while these gates remain. The local platform is a working implementation with explicit provider/legal/deployment boundaries.
