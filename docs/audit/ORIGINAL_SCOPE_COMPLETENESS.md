## Gaps found and corrected in this audit

- Staff overview property selection and audit/finance controls combined capabilities from different property grants. Each selected property now determines its own report/audit/write access; a browser regression exercises a user with three different property roles.
- Native electronic signing was absent; only manual signed uploads existed. Added one-use expiring document-bound signing review, verified contacts and TOTP step-up, explicit disclosure/name/intent, scanned signed PDF, immutable event/evidence hashes, replay prevention and independent execution review. Old issued source snapshots are now immutable too.
- Execution could accept a clean-scanned file after its review state was rejected. Execution now checks review state, and an audited staff return-for-signature workflow preserves old evidence and supports a new version.
- Signed copies lacked a direct resident lease-card link, and agreement reading relied on download. Added signed-file download and in-page agreement reading.
- Approved tenancy conditions were not displayed/hashed before application submission. Added catalogue and waitlist review, current-content hash validation and versioned consent.
- Reports omitted defined renewal rates, invoice collection performance and time-bucketed complaint trends. Added exact source-record debt/reconciliation/CSV, rental arrears, renewal cohorts, room utilisation and monthly complaint/service counts with stated denominators and separate finance access.
- Intrusion monitoring had no persistent triage workflow. Added privacy-preserving repeated-auth/access/CSRF/rate/malware/scan-failure signals, high-severity thresholds, administrator notifications and scoped acknowledge/resolve with audit.
- Added missing registration/logout/preferences/privacy-request/recovery/read audit events. Registration and verification outbox creation are atomic. Visible catalogue/portal records refresh every 30 seconds and on focus.
- Added role-based practical training exercises and a scheduled weekly security audit. Live training/support remain human service handover items, not completed by writing code.
