# Client inputs and production gates

No real corporate, legal, property or merchant facts were inferred from the reference system.

| Decision / input                                      | Current development behavior                                                                                               | Required production action                                                                                                                                 |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Logo, photography, legal entity, contacts, directions | Neutral typography and clearly labelled architectural illustrations; synthetic properties                                  | Supply approved assets and factual catalogue copy; replace demo fixtures                                                                                   |
| Inventory, floors, bed categories, accessibility      | Synthetic two-property fixture, editable room/bed hierarchy                                                                | Load verified inventory; review accessible-room allocation policy                                                                                          |
| Currency and price/rate policies                      | Explicit USD fixture; room/bed/date/minimum-term rates with retained reservation snapshots; integer calendar-day prorating | Confirm currency per property and term/seasonal policy; approve all rate/deposit/cancellation rules                                                        |
| Hold TTL / waiting priority                           | Configured 15 minute default, demo 60 minutes; FIFO with audited 0–10 priority                                             | Approve TTL, waiting priority and cancellation policy                                                                                                      |
| Lease terms and signature method                      | Clearly nonlegal demo template; auditable manual upload and native authenticator-backed explicit-consent signing           | Zimbabwe counsel approves template versions, execution evidence, signer verification and retention; select external e-sign provider if required            |
| Paynow                                                | Disabled by default; hosted connector code and signed polling tests                                                        | Real merchant integration, currency/method capability verification, public HTTPS callbacks, sandbox contract tests; no money movement presumed             |
| Email / mobile verification                           | Durable delivery jobs fail explicitly without credentials; demo contacts preverified only                                  | Resend verified sender and SMS Pop approved sender/account; real delivery/recovery tests                                                                   |
| Medical and ID data                                   | Encrypted quarantine, separate medical capability, version hashes and download audit                                       | Data protection assessment, lawful bases, consent text, retention periods, DPO contact and access/erasure handling approval before collecting real records |
| ERP / SIS / PMS                                       | Permissioned CSV adapters and scoped API exports                                                                           | Choose providers and systems of record; supply sandbox APIs, mappings, permitted data flows and institutional consent                                      |
| Hosting / keys / backups                              | Local encrypted volume, independent encryption keys, restore drill                                                         | Select Zimbabwe-accessible hosting, KMS/secrets manager, encrypted disks, offsite versioned backups and tested fresh-host recovery                         |
| Security monitoring / support                         | Scoped audit view, queue exceptions, health endpoint and SLA reminders                                                     | Route alerts to approved on-call monitoring; approve response SLOs, retention, patch cadence and incident process                                          |

Production release is blocked until required inputs, fresh-host/container checks, provider tests, independent security/legal review and all remaining acceptance gaps are resolved. Local test success is not a compliance certification.
